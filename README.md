## 🗂 Охват 4 официальных реестров ФИПС

1. **RUTM** — *Реестр товарных знаков и знаков обслуживания РФ*:
   - Все национальные регистрации РФ (свидетельства № 1 — 1 265 000+).
   - Статусы: действует, прекратил действие, продлен, аннулирован.
2. **WKTM** — *Реестр общеизвестных в РФ товарных знаков*:
   - Товарные знаки с особым правовым статусом и бессрочной правовой охраной (свидетельства № 1 — 290+).
3. **WOTM** — *Международные товарные знаки с указанием РФ*:
   - Товарные знаки по процедуре Мадридского соглашения и Протокола к нему (ВОИС / WIPO).
4. **RUTMAP** — *Реестр заявок на регистрацию товарных знаков РФ*:
   - Все открытые заявки на товарные знаки (2 000 000+ карточек), находящиеся на этапе формальной экспертизы или экспертизы заявленного обозначения. Позволяет выявлять риски до регистрации конкурентов.

## 💡 Примеры аналитических SQL-запросов

### Поиск товарных знаков по названию и классам МКТУ (PostgreSQL)

```sql
SELECT 
    reg_number, 
    mark_name, 
    holder, 
    reg_date, 
    expiry_date
FROM fips_trademarks
WHERE 
    status = 'действует'
    AND mktu_classes && ARRAY[35, 42]
    AND mark_name ILIKE '%ТЕХНО%'
ORDER BY reg_date DESC
LIMIT 50;
```

### Анализ активности правообладателей за последний год (ClickHouse)

```sql
SELECT 
    holder, 
    count() AS total_trademarks,
    groupUniqArray(mktu_class) AS active_classes
FROM fips_registry.trademarks
WHERE toYear(reg_date) = 2026
GROUP BY holder
ORDER BY total_trademarks DESC
LIMIT 20;
```
